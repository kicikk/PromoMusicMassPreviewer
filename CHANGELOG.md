# Changelog

Newest first. Download: [latest release](https://github.com/kicikk/PromoMusicMassPreviewer/releases/latest).

## v20261106_b5.9 - 2026-11-06

- The Polish interface uses Polish characters everywhere (the Spotify window still had
  some texts without them).
- The version is now part of the file name, e.g.
  `Promo_Music_Mass_Previewer_v20261106_b5.9.exe`. When updating, put the new file in
  the same folder and delete the old one.
- New project address: github.com/kicikk/PromoMusicMassPreviewer (old links redirect).

## v20261106_b5.8 - 2026-11-06

- The activation window in Polish now uses proper Polish characters.
- The exe carries its version: right-click -> Properties -> Details shows the same
  number as the bottom of the panel.
- The project page has a direct download link, the current version and this changelog.

## v20261028_b5.7 - 2026-10-28

First public release.

- Windows 10/11, 64-bit, a single exe - no installation.
- Free 3-day trial, then a free activation key for your computer - see
  [Activation](https://github.com/kicikk/PromoMusicMassPreviewer#activation).
- Spotify mode (Premium): an artist's whole discography, an album or a playlist,
  previewed and rated like files.
